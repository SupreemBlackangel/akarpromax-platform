# Root Cleanup Report

root and a classification of each. No file was deleted by this phase; this report
records the inventory and recommended action so cleanup is a conscious, reviewed
step.

Status: **report only** — deletion is intentionally deferred to a follow-up.

## Classification legend

| Class | Meaning |
| --- | --- |
| `REMOVE_FROM_GIT` | Tracked in the repo but should be removed from history/tracking (dev-only tooling, secrets-shaped content). |
| `ALREADY_IGNORED` | Never tracked; already excluded by `.gitignore`. Safe to delete locally. |
| `KEEP` | Legitimate project file. |
| `REVIEW` | Pre-existing decision; recommend revisiting outside Phase 0. |

Recommended action for the `_e2e_*.mjs` set: delete with `git rm _e2e_ads.mjs
_e2e_clean.mjs _e2e_seed.mjs` in the cleanup commit, and replace with a single
opt-in script under `scripts/` that reads DB credentials from the environment
(`MYSQL_URL`), never hardcodes them, and refuses to run when `NODE_ENV=production`.
