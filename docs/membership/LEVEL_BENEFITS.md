## 4. Non-Dark Pattern Rules

### What We Do NOT Do

- ❌ Block basic features for NEW users
- ❌ Create fake urgency ("Upgrade NOW!")
- ❌ Hide features behind paywalls
- ❌ Send notification spam
- ❌ Create fake achievements
- ❌ Use dark patterns for retention

### What We DO

- ✅ Provide real value at every level
- ✅ Show progress transparently
- ✅ Reward genuine quality
- ✅ Enable organic growth
- ✅ Respect user attention

When level drops:
- Grace period notification
- Benefits transition period
- Support for improvement
- Clear improvement path

## 8. Commercial Plan Separation

**Level benefits are NOT tied to commercial plans.**

| Concept | Source | Control |
|---------|--------|---------|
| Level Benefits | Reputation level | Automatic |
| Commercial Benefits | Paid plan | Purchased |

**Example:**
```
User with FREE plan + GOLD level
→ Gets GOLD benefits (automatic)
→ Does NOT get BUSINESS plan benefits (not purchased)
```

**Example:**
```
User with ENTERPRISE plan + NEW level
→ Gets ENTERPRISE plan benefits (purchased)
→ Does NOT get GOLD level benefits (not earned)
```
