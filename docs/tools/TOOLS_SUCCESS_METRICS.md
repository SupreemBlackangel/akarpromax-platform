# Tools Success Metrics

Future metrics to track for /tools experience quality.

## Engagement Metrics

- Tool completion rate (input → result)
- Time to first result
- Copy/share action rate
- Example button usage rate
- Advanced options expansion rate

## Mobile Metrics

- Touch target miss rate (taps outside interactive area)
- Horizontal overflow incidents
- Safari auto-zoom triggers
- Mobile vs desktop tool usage split

## Accessibility Metrics

- Keyboard navigation completion
- Screen reader result announcements
- Focus ring visibility score

## Performance Metrics

- /tools bundle size
- Heavy tool lazy loading time (PDF, OCR, DXF)
- First contentful paint for /tools

## Quality Metrics

- Calculation regression incidents
- RTL rendering issues
- Dark mode rendering issues
- Ad safe-zone violations
